Crops are one of the main features of Gelli Fields, being the main way to make glim. They can be planted from ![](../../assets/images/gelli fields/items/Apple-Tree-Seeds.png) seeds bought in the shop or seeds obtained as crop variants.

## Starter Crops

Each biome in the game contains three crops that can be bought from the shop. These are starter crops, and are *always* available to buy. As these crops are specific to each biome, here is a list of which are available in each biome.

| Crop Seeds    | Biome             |
|:--------------|:------------------|
|Turnap Seeds   | Friendly Fields (Base)|
|Sweetroot Seeds| Friendly Fields (Corruption 1)|
|Red Pompy Seeds| Friendly Fields (Corruption 2)|
|Rocktato Seeds | Rocky Retreat (Base)|
|Metamorphshroom Seed| Rocky Retreat (Corruption 1)|
|Green Kanno Seeds| Rocky Retreat    (Corruption 2)|

## Variant Crops

Variant crops are a special type of crop that can be dropped when a crop is harvested with a set chance. These crops give more glim than the base crop. Variant crops are the main crop progression in Rocky Retreat, though they are still present in other biomes.
